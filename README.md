# 🪨 Rock Paper Scissors 📄

My second Python project — a simple command-line Rock Paper Scissors game where you play against the computer.

## 🎮 Features

* 🪨 Rock, Paper, Scissors gameplay
* 🤖 Random computer choices
* ✅ User input validation
* 🏆 Player and computer score tracking
* 🤝 Draw tracking
* 🔄 Play again option
* 🥇 Final winner announcement

## 🛠️ Built With

* Python
* `random` module

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python rock_paper_scissors.py
```
